대화 자동 분석

정산 항목 추출

누가 얼마를 냈는지, 누가 참여하는지, 어떻게 나눌지를 구조화된 JSON으로 반환합니다.

모델 비교 실험

EXP-A~F 매트릭스로 gpt-4o-mini부터 gpt-4.1까지 정확도·비용을 자동 비교합니다.

API 엔드포인트

FastAPI 기반 3개의 주요 엔드포인트

POST
/api/process
실운영 체인. 대화 텍스트를 받아 정산 항목을 추출하여 반환합니다. Simplified chain (2-stage LLM + 규칙 파싱) 사용.
운영용
{"final_result": [{"place": "식당",
 "payer": "0", "item": "저녁식사",
 "amount": 45000, "participants": ["0","1","2"],
 "constants": {}, "ratios": {"0":1,"1":1,"2":1}}]}
POST
/api/process-file
파일 기반 처리. JSON 대화 파일을 로드하여 처리합니다. 개발·테스트 목적용이며 청킹 옵션을 지원합니다.
개발용
Query params:
• conversation_file
• stage1_model, stage2_model
• prompt_file, use_chunking
POST
/api/evaluate-with-processing
실험·평가용. expected_output(정답)을 함께 제출하면 처리 결과와 DeepEval 정확도 점수를 함께 반환합니다. 모델 비교 실험(EXP-A~F)에 활용.
평가용
추가 필드:
• expected_output (필수) — 정답 정산 항목 배열
• evaluation_model (기본: gpt-4o) — DeepEval 평가 모델
반환: 정산 결과 + 정확도 점수 (precision, recall, f1)
