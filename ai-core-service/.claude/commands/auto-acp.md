# Auto ACP (Add / Commit / Push)

코드의 변경사항을 파악하고 안전하게 git add / git commit / git push를 실행합니다.

## 커밋 순서

1. **변경사항 확인**: `git status`로 변경된 파일 목록 표시
2. **변경 내용 리뷰**: `git diff`로 구체적인 변경사항 미리보기
3. **사용자 확인**: "이 변경사항들을 커밋하시겠습니까?" 확인
4. **브랜치 확인**: 현재 브랜치가 올바른지 확인
5. **스테이징**: `git add .`으로 변경사항을 스테이징 영역으로 전달
6. **커밋 메시지 생성**: 아래 규칙에 따른 커밋 메시지 생성
7. **커밋 메시지 최종 확인**: 생성된 커밋 메시지 확인받기
8. **커밋 실행**: `git commit -m "커밋 메시지"`로 커밋 진행
9. **푸시 실행**: 적절한 원격 브랜치로 푸시
10. **결과 확인**: 모든 작업 완료 후 상태 확인 및 알림 출력

## 커밋 메시지 규칙

- 형식: `Update yymmdd data`
- `yymmdd`에는 당일 날짜를 숫자로 표기

**예시**:
- 2025년 09월 06일 → `Update 250906 data`
- 2026년 04월 12일 → `Update 260412 data`

## 에러 처리

- **변경사항 없음**: "커밋할 변경사항이 없습니다" 메시지 출력 후 종료
- **푸시 실패**: 네트워크 오류 시 로컬 커밋은 유지하고 푸시 재시도 안내
- **중단 요청**: 사용자가 확인 단계에서 거부 시 안전하게 중단
